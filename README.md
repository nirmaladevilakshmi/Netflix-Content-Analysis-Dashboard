## 🍿 About The Project

**Netflix Content Analysis Dashboard** is an interactive **Power BI dashboard**
created to explore and analyze Netflix content data.

This project focuses on understanding Netflix content through:

- 🎬 Movies and TV Shows
- 🌍 Countries
- 🎭 Genres
- ⭐ Ratings
- 📅 Release-year trends
- 📊 Content distribution
